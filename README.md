## 🖨️ Como Exportar para PDF a partir do HTML

1. Abra o arquivo `curriculo.html` em qualquer navegador web (Google Chrome, Firefox, Brave, Edge).
2. Pressione **`Ctrl + P`** (ou `Cmd + P` no macOS).
3. Selecione o destino como **Salvar como PDF**.
4. *(Opcional)* Nas configurações de impressão:
   * **Margens**: Padrão ou Mínimas.
   * **Gráficos de segundo plano**: Ativado (caso deseje os acentos em cores).
   * O layout converte automaticamente para fundo branco e texto escuro de alta legibilidade para economia de tinta.
